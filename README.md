# Online Rental Outfit Platform

A full-stack Django project using MySQL and Tailwind CSS.

## Features
- Custom User Authentication
- Outfit Inventory Management
- Date-based Booking System
- Late Fee Tracking
- Modern Responsive UI

## Quick Start
1. Create MySQL DB: `rental_db`
2. `pip install -r requirements.txt`
3. `python manage.py tailwind install`
4. `python manage.py migrate`
5. `python manage.py createsuperuser`
6. `python manage.py runserver`

For detailed instructions, see `walkthrough.md`.
